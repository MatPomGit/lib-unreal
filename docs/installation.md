# Instalacja

Python 3.11+ i aktywny Unreal Editor z włączonym Unreal MCP i Toolsets. Instalacja lokalna: `python -m pip install -e .`. Uruchomienie odczytu: `python -m lib_unreal`. Wydanie i instalacja z registry nie są dostępne. Adres można przekazać jako `--endpoint`, ale tylko dla loopback. Stan silnika nie jest sprawdzony na Andromedzie.
